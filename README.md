# Flowix — سامانه تعمیرگاه

![پیش‌نمایش Flowix](cover.png)

پلتفرم SaaS چندمستأجری برای پذیرش، پیگیری، تعمیر، انبار، مالی و گارانتی تعمیرگاه‌ها.

هر تعمیرگاه پس از ثبت‌نام و تأیید سوپرادمین، پنل مستقل خود را دارد. مشتری بدون ورود به پنل، با کد رهگیری وضعیت دستگاه را می‌بیند، هزینه را تأیید می‌کند و آنلاین پرداخت می‌کند.

محصول عمومی با نام **Flowix** عرضه می‌شود ([flowix.ir](https://flowix.ir)). رابط کاربری کاملاً راست‌چین و فارسی است.

**توسعه‌دهنده:** گروه برنامه‌نویسی کا جی اس ام  
**استک:** Laravel 12 · Inertia.js · Vue 3 · TypeScript · Tailwind CSS

## نقش‌ها

| نقش | دسترسی اصلی |
| --- | --- |
| `super_admin` | کل پلتفرم؛ بدون تعلق به یک مغازه |
| `admin` | مدیر مغازه: تنظیمات، کارکنان، اشتراک، همه عملیات میز |
| `reception` | پذیرش، پرونده‌ها، مشتریان، چاپ |
| `technician` | فقط پرونده‌های تخصیص‌یافته |
| `accountant` | گزارش پرداخت، دفتر حساب، هزینه‌ها |

مغازه تا زمان تأیید سوپرادمین در `/shop/pending` می‌ماند. در صورت تعلیق، دسترسی به `/shop/suspended` محدود می‌شود.

## گردش پرونده تعمیر

```
ثبت‌شده → دریافت‌شده → عیب‌یابی → اعلام هزینه → تأیید مشتری
       → در حال تعمیر → آماده تحویل → تحویل‌شده → بسته
```

وضعیت‌های پایانی: تحویل‌شده، بسته، لغو شده، رد توسط مشتری.

## پشته فناوری

- Laravel 12 + PHP 8.2
- Inertia.js + Vue 3 + TypeScript
- Tailwind CSS (RTL / Vazirmatn)
- Spatie Permission
- DomPDF و mPDF (فاکتور، رسید، گارانتی، QR)
- Jalali (`morilog/jalali` + `jalaali-js`)
- اسکن بارکد: `html5-qrcode`
- صف‌کار: پیامک وضعیت و کمپین بازاریابی

## یکپارچه‌سازی‌ها

**پیامک:** Log (تست)، کاوه‌نگار، SMS.ir، ملی‌پیامک، صبا پیامک

**پرداخت:** زرین‌پال، آیدی‌پی، زیبال، سندباکس داخلی (`/payments/sandbox/...`)

با `SMS_DRIVER=log` پیامک‌ها فقط در `storage/logs/laravel.log` نوشته می‌شوند. اگر مرچنت درگاه خالی باشد، پرداخت از سندباکس داخلی عبور می‌کند.

## مسیرهای اصلی

```
/                      لندینگ
/shop/register         ثبت‌نام تعمیرگاه
/s/{slug}              ویترین مغازه
/track                 جستجوی پیگیری
/t/{token}             پنل مشتری
/warranty              استعلام گارانتی
/acceptance            پذیرش (میز)
/dashboard             داشبورد مغازه
/technician/cases      پنل تکنسین
/admin/cases           پرونده‌ها
/admin/customers       مشتریان
/admin/inventory       انبار
/admin/accounting      مالی
/admin/warranties      گارانتی
/admin/sms             پیامک بازاریابی
/admin/subscription    اشتراک و کیف‌پول
/admin/settings        تنظیمات مغازه
/platform              پنل سوپرادمین
/login                 ورود
```

فایل‌های فاکتور، رسانه و گارانتی از مسیرهای signed (`/secure/...`) یا توکن پیگیری سرو می‌شوند؛ فایل خام در `public` قرار نمی‌گیرد.
